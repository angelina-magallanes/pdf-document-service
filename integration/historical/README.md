# Integración histórica

Este manifiesto conserva una combinación anterior de API, Extractor y Documents.
Su [resultado](validation.md) corresponde únicamente a los commits de
[versions.json](versions.json). Para repetirla desde la raíz:

```bash
python3 scripts/integration_stack.py --versions integration/historical/versions.json
```

El escenario predeterminado y su resultado más reciente están documentados en
[Integración actual](../current/README.md).
